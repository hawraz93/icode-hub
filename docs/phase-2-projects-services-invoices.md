## داتای هەبوو

Migrationـەکان تەنها شت زیاد دەکەن. تاکە گۆڕینی داتا: پڕۆژە هەبووەکان `is_public = true` دەبن تا پۆرتفۆلیۆ وەک خۆی بمێنێت.

`php artisan finance:backfill` ئێستا ئەمانەش دەکات:
- بۆ هەر خزمەتگوزارییەک ماوەی ئێستا هاوردە دەکات. نرخی biennial وەک نرخی دوو ساڵ دەمێنێتەوە و ×2 ناکرێت.
- `cost_basis` تەنها کاتێک ڕوونە: VPS و تێچووی 0 → هاوبەش؛ بێ VPS و تێچوو > 0 → ڕاستەوخۆ؛ VPS و تێچوو > 0 → نەزانراو + ڕاپۆرت.
- snapshotی زانیاری کڕیار بۆ وەسڵە دەرچووەکان (`captured_at` ـی ڕۆژی backfill).
- بەستنەوەی پڕۆژە تەنها پێشنیار دەکرێت، هەرگیز خۆکار نابەسترێتەوە.

ڕێکار وەک قۆناغی 1: backup، `migrate`، `finance:backfill --dry-run`، پاشان `finance:backfill`.
Rollback: `php artisan migrate:rollback --step=3`.
